# HKDSE Study Hub

Simple static website for HKDSE-focused study support.

## Features

- Subject-based browsing
- Topic tutorials with keypoints
- Exercise bank with questions from HKDSE, CE and A-Level sources
- 100 generated, syllabus-aligned practice questions per subject
- Current subjects: Mathematics, English, Physics, Chemistry, Biology, Economics, BAFS, ICT, History (900 questions total)
- Automatic syllabus filtering: only questions marked in HKDSE syllabus are displayed

## Run locally

Open `/home/runner/work/dse/dse/index.html` in your browser.

## Public hosting (GitHub Pages)

This repository is configured to deploy via GitHub Actions to GitHub Pages.

Expected URL:

`https://cc-cc-ll.github.io/dse/`

If this is the first deployment, enable **Settings → Pages → Source: GitHub Actions** in the repository.
